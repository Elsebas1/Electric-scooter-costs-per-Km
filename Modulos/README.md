# Python Modules

## General description

This repository is a dedicated space for learning, practicing, and mastering modular programming in Python. It contains a structured collection of practical exercises, scripts, and small projects designed to demonstrate how to break down complex problems into clean, reusable, and maintainable components.

## Folders

 * Divisas cambio: This folder is an exercise about foreign exchange especially USD/COP
 * ejercicios: This folder contains football league, Pipeline, store and a banking exercise where the informations will be updated as the user or enters data. 
 * cripto.py: This script show how many ethereum's someone need to buy 1 bitcoin.
